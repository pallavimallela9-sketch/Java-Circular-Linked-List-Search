# Search an Element in Circular Linked List

A Java program to search for a particular element in a circular linked list.

## Features

- Creates a circular linked list
- Takes an element to search
- Displays the position if the element is found

## Technologies Used

- Java
- Scanner
- Circular Linked List

## Concepts Used

- Nodes
- Circular traversal
- Searching
- do-while loop

## Output

Circular Linked List:
10 -> 20 -> 30 -> 40 -> HEAD

Enter element to search: 30
Element found at position 3
